Post a GTA 6 meme on X. The meme (`meme.png`, built by `build_meme.py`) is a Vice City sunset: "13 YEARS. GTA 6 IS FINALLY HERE." with make.fun's ghost mascot cruising in, and the pitch that while you waited, my AI agent earned real money on make.fun. The X post's address goes in `POST.json`; `main.ts` copies it to `/output` for the house to read the post from X.

## Run it

```sh
node main.ts
```

Node 22, standard library only, no network.
